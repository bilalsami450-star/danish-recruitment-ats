# Muhammad Danish — Recruitment Pipeline & ATS Workflow

Standalone, Vercel-ready portfolio build reconstructed from the ATS portfolio brief.

## Deploy
- Install Vercel CLI: `npm i -g vercel`
- From this folder run: `vercel`
- For production: `vercel --prod`

This build is intentionally public and view-only. It contains fictional demo candidate data only.

## Important
The original ChatGPT Site projection cannot export its raw source. This is an independent standalone reconstruction. Real persistent admin/editor email invitations require a database/auth provider and are not represented as working functionality in this static portfolio build.
